# Workflow diagram

`workflow.excalidraw` is the editable source; `workflow.svg` is its README preview.
Open the source in [Excalidraw](https://excalidraw.com), edit it, and export an SVG
with the background enabled. Commit both files together.

The diagram uses native shapes and text, not a flattened image. The light canvas
keeps labels readable in either GitHub theme. The SVG includes an accessible title
and description. No diagram tooling is required to install or run the package.
