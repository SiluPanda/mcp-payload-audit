# Workflow diagram

`workflow.excalidraw` is the editable source; `workflow.svg` is its README preview.
Open the source in [Excalidraw](https://excalidraw.com), edit it, and export an SVG
with the background enabled. Commit both files together.

The diagram uses native shapes and bound text, not a flattened image. Its pastel
fills, thin sketchy outlines, dashed groups, and Virgil handwriting follow the
`excalidraw-pastel` style. Preserve `fontFamily: 1` (Virgil), including when editing
code-like labels; do not replace it with Excalifont or a system font.

The near-white canvas keeps labels readable in either GitHub theme. The SVG
includes an accessible title and description and embeds Virgil so it renders
without a font download. The embedded font retains its SIL Open Font License;
see [Virgil-LICENSE.txt](Virgil-LICENSE.txt). No diagram tooling or font dependency
is required to install or run the package.
